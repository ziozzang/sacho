# 이벤트의 경고·오류 기록 보기

Copyright Jioh L. Jung <jung@jioh.net>

대시보드에서 경보 목록, 서비스 상태, 이력 막대 또는 수치 그래프의 점을 누르면 아래에 관련 로그 패널이 열립니다. 다른 이벤트를 누르면 대상과 내용이 바뀝니다. 닫기 버튼 또는 Esc로 닫고, 높이 슬라이더로 크기를 조절합니다. 기본 조회 범위는 이벤트 앞뒤 10분이며 앞뒤 1분부터 1,440분까지 바꿀 수 있습니다. 심각도 선택, 메시지 검색, 더 보기로 기록을 찾습니다. 검색 결과가 없는 페이지에도 더 보기가 있으면 다음 기록을 계속 검색할 수 있습니다.

원문 검사 출력은 기존과 동일하게 **관리자만** 볼 수 있습니다. 인증 없는 운영 모드에서는 기존 관리자 API와 마찬가지로 접근을 허용합니다. 공개 페이지 방문자는 패널을 열 수 있지만 관리자 인증이 없으면 안내만 나옵니다. 서비스가 공개돼 있다는 이유로 원문 출력을 공개하지 않습니다.

자료는 사초가 이미 보관하는 로컬 검사, 원격 수집 에이전트 보고, 검사·수집 실패 기록입니다. `outage` 기록은 오류, `degraded` 기록은 경고로 분류합니다. 정상 검사는 포함하지 않습니다. 이벤트 대상은 서비스 이름과 실행 노드(로컬 서버 또는 원격 에이전트), 검사 종류로 표시합니다. 같은 호스트라는 추정만으로 다른 서비스의 기록을 섞지 않습니다.

호스트 시스템 로그, 서비스 파일 로그, 사초 프로세스의 tracing 출력은 현재 검사 자료에 보관되지 않습니다. 이를 함께 보려면 서비스·호스트 식별자와 시각·심각도를 포함하는 로그 수집 및 보존 기능을 별도로 추가해야 합니다. 이번 변경은 새 로그 수집이나 운영 설정을 추가하지 않습니다.

## 기술 메모

`GET /api/admin/events/{event_id}/logs`는 기존 관리자 인증을 적용합니다.

- 경보 ID는 `/api/incidents`의 `id`입니다. 기준 시각은 경보가 열린 시각입니다.
- 검사 ID는 `check:<숫자>`이며 `/api/history/{item_id}`의 각 구간에 추가한 `event_id`로 얻습니다. 기준 시각은 그 구간에서 가장 심각한 상태의 최근 실제 검사 시각입니다.
- `item:<서비스 ID>`는 가장 최근 보관 검사를 기준으로 조회합니다. 이력의 빈 구간에는 이벤트가 없습니다.
- `window`: 앞뒤 초 단위 범위, 기본 600, 최대 86,400.
- `severity`: `all`, `error`, `warning`. 기본값은 경고와 오류 모두입니다.
- `search`: 비밀값을 가린 메시지를 검색합니다. 최대 256바이트입니다. 가려진 값으로 원문 존재 여부를 추측할 수 없도록 원문은 검색하지 않습니다.
- `limit`: 기본 30, 최소 1, 최대 100. `before`에는 응답의 `next_before`를 넣습니다. ID 역순으로 이어 보므로 같은 초에 생긴 기록도 빠뜨리지 않습니다.

응답에는 이벤트와 서비스 ID, 대상 이름, 출처, 기준 시각, 범위, `logs`, `next_before`가 있습니다. 각 기록에는 `id`, `at`(Unix 초), `severity`, `source`, `message`가 있습니다. 보관이 끝난 이벤트는 404를 반환합니다.

한 요청에서 최대 200건을 검사하고 다음 건은 유무만 확인합니다. 출력·설명은 SQL에서 각각 8,192문자로 제한하며, 반환 메시지는 4,096문자, 직렬화한 로그 합계는 128KiB 이하입니다. 정렬은 기존 서비스별 검사 ID 색인을 사용합니다. 범위가 커도 전체 원문을 메모리에 올리지 않습니다. 검색 또는 응답 크기 제한으로 페이지가 일찍 끝나면 `next_before`로 계속 조회합니다.

토큰·비밀번호·인증 헤더·쿠키·개인 키 등의 이름, 긴 키 형태의 문자열, URL 인증 정보가 보이는 필드는 전체를 `[redacted]`로 바꿉니다. 설명과 출력은 따로 가리므로 안전한 설명은 유지됩니다. 여러 줄로 된 값도 필드 전체를 가립니다. 정상적인 긴 식별자도 가려질 수 있습니다. 이 기능은 비밀값을 애초에 로그에 남기지 않는 원칙을 대체하지 않습니다.

검증: `make check`, `make test`, `python3 tests/event_logs.py`. 마지막 명령은 Playwright Chromium이 필요하며, 실제 서버의 API와 패널 열기·바꾸기·닫기·높이·필터·더 보기 및 모바일 화면을 시험합니다. 화면 캡처 경로는 `SACHO_SCREENSHOTS` 또는 `runtime/screenshots`입니다.
